## Features
- **Now Playing display:** album art, track title, and artist
- **Controls:** play/pause, next, previous, and a slider to adjust volume and playback

## BOM
| Part | Qty | Notes |
|------|-----|-------|
| ESP32-WROOM-32E | 1 | Main Controller |
| AMS1117-3.3V LDO | 1 | Regulates 5V down to 3.3V for ESP32-S3 and other 3.3V peripherals. |
| 2.4 Inch TFT LCD with XPT2046 Touch Controller | 1 | Combined display and touch input module using SPI interface for both display and touch. |
| M3 Heat-Set Inserts | 8 | Embedded brass inserts to provide durable threads in the 3D-printed enclosure. |
| M3 Socket Head Cap Screws | 16 | Screws for joining enclosure halves and securing the display bezel. |

## Structure Itself
All 3D printed parts. There are 4 Parts in total: A flooring, body, cover, and upper layer. These parts have intricate designs to make the gadget unique and not bland. The gadget is able to stand at a 45 degree from its surface.
